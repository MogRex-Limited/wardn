# wardn

Simple, opinionated authorization for Go. Define your own roles, permissions and scopes; wardn handles the rest.

> **Status: v1.0.0.** Stable: nothing in v1 will break code, data or decisions that rely on it ([stability promise](docs/STABILITY.md)). What's in the release: [CHANGELOG](CHANGELOG.md).

```bash
go get github.com/MogRex-Limited/wardn@v1.0.0
```
