# Logos

Brand logos for the "Works with" row on the landing page, from
[Simple Icons](https://simpleicons.org) v16.35.0 (CC0). Each file was changed
only to follow the text colour (`fill="currentColor"`), hide it from screen
readers (the chip's text is the label) and drop its `<title>`.

The logos are trademarks of their owners and are used only to say that wardn
works with these products.
